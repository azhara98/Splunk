# Dashboard Creation

A Splunk dashboard was created using the analyzed HTTP log data to visualize relevant security events and support monitoring.

## Objective

To create a dashboard in Splunk that presents useful information from the HTTP log data through visualizations and dashboard panels.

## Key Highlights

- Created SPL-based dashboard panels
- Used extracted fields in dashboard panels
- Created visualizations for HTTP log analysis
- Displayed relevant security event information
- Used Splunk Dashboard Studio
- Built a dashboard for security monitoring

## Dashboard

The dashboard contains visualizations based on the analyzed HTTP log data and provides a consolidated view of relevant security information.

## Tool Used

- Splunk
- SPL
- Dashboard Studio
