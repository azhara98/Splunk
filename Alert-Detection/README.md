# Alert Detection

Alert detection was performed in Splunk using the analyzed HTTP log data to identify relevant security events.

## Objective

To create SPL-based detections and configure alerts for relevant events identified during HTTP log analysis.

## Key Highlights

- Analyzed HTTP log events in Splunk
- Created SPL-based detection queries
- Identified relevant security events
- Configured alert conditions in Splunk
- Tested and verified alert results
- Used detected events for further investigation

## Detection

The HTTP log data was searched using SPL queries to identify relevant events. Detection conditions were configured as Splunk alerts and the results were verified.

## Tool Used

- Splunk
- SPL
